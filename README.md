# Arcforge — games-site

Public marketing/hub site for Arcforge, a mobile games studio. Each game ships natively on
iOS and Android from its own private repository; this site is where they get discovered —
descriptions, screenshots, and (where it makes sense) playable web trailers.

Live: https://bpupadhyaya.github.io/games-site/

Static site, no build step — `index.html` + `assets/`.
